# Security Policy

## Reporting Security Issues
If you discover a security vulnerability in this project or its container configuration, please do not open a public issue.

Instead, please send an email directly to the maintainer:
- **Maintainer**: Abhin M

Please include:
1. Steps to reproduce the vulnerability.
2. Affected container tags or scripts.
3. Potential impact.

We will acknowledge receipt within 48 hours and work toward a timely patch.
